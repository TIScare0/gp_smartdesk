MODEL

Gemini

Google's model family. Fast, large context, generous free tier.

Bring your own Gemini key from Google AI Studio to get unlimited, priority access instead of using AURA's shared free tier.

How to get your key
1

Open Google AI Studio

Go to aistudio.google.com and sign in with any Google account. No separate signup is needed — your existing Google login works.

2

Create an API key

Click Get API key in the left sidebar, then Create API key. Choose an existing Google Cloud project or let it create one for you automatically.

3

Copy the key

Your key appears as a long string starting with AIza.... Copy it immediately — you can always view it again later from the same page.

4

Paste it into AURA

Open Settings → Model & API and paste it into the Gemini field. It saves automatically as you type.

MODEL

Claude

Anthropic's model family. Careful reasoning, long context, strong writing.

Bring your own Anthropic key from the Claude Console to get unlimited, priority access instead of using AURA's shared free tier.

How to get your key
1

Open the Claude Console

Go to console.anthropic.com and sign in or create an account. This is separate from a regular claude.ai login.

2

Create a new key

Under API Keys, click Create Key. Give it a name like "AURA" so you can identify it later.

3

Copy it now

The full key is only shown once and starts with sk-ant-.... Copy it immediately — if you lose it, you'll need to generate a new one.

4

Paste it into AURA

Open Settings → Model & API and paste it into the Claude field.

MODEL

Cohere

Strong reasoning and retrieval-focused models, with a no-cost trial key.

Bring your own Cohere key from your Cohere dashboard to get unlimited, priority access instead of using AURA's shared free tier.

How to get your key
1

Create a Cohere account

Visit dashboard.cohere.com and sign up with your email or a Google/GitHub account.

2

Find your trial key

Once logged in, go to the API Keys tab. A trial key is generated for you automatically — no card required for the free tier.

3

Copy the key

Click the key to reveal and copy it. Trial keys are rate-limited but reset regularly, which is plenty for everyday use in AURA.

4

Paste it into AURA

Open Settings → Model & API and paste it into the Cohere field.

MODEL

OpenAI-compatible

Works with OpenAI directly, or any provider that mirrors its API format.

Bring your own OpenAI (or compatible) key to get unlimited, priority access instead of using AURA's shared free tier.

How to get your key
1

Open the API platform

Go to platform.openai.com and sign in. This is separate from a regular ChatGPT login and may ask you to set up billing.

2

Create a new secret key

Under API keys, click Create new secret key. Give it a name like "AURA" so you can identify it later.

3

Copy it now

The full key is only shown once. Copy it immediately — if you lose it, you'll need to generate a new one.

4

Paste it into AURA

Open Settings → Model & API and paste it into the OpenAI-compatible field.

AURA is model-agnostic by design: bring the provider you already trust, and AURA handles the editorial layer on top — built for people who think in both prose and code.
